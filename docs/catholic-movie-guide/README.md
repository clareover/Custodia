# Catholic Movie Guide

Early foundation for a Catholic parents’ guide and content resource website.

## What’s included

- **index.html** — Home page with hero, feature cards, and placeholder movie grid
- **browse.html** — Browse / search page (filters are visual placeholders for now)
- **movie.html** — Single movie detail template with sections ready for timestamps and Catholic analysis
- **criteria.html** — Explanation of the Catholic rating scale and evaluation criteria
- **about.html** — Project purpose and status
- **css/styles.css** — Clean, dignified styling (navy + soft gold palette, serif headings)
- **js/main.js** — Basic mobile menu and search behavior

## How to view

Simply open `index.html` in any modern browser (Chrome, Firefox, Safari, Edge).  
No build step or server required for the current static version.

## Design notes

- Professional, calm, family-friendly aesthetic
- Responsive (works on phone, tablet, desktop)
- Rating badges (A-I through O) styled and ready
- Placeholder content only — no actual objectionable scene data yet
- Easy to expand later with a real database or CMS
